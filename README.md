## 🛠 Technologies

- HTML5
- CSS3
- Responsive Design
- Déployé sur Vercel

## ✨ Fonctionnalités

- 🍕 Présentation du restaurant italien
- 📋 Menu interactif (pizzas, burgers...)
- 💰 Affichage des prix
- 🎨 Design élégant et moderne
- 📱 100% responsive (mobile / tablette / desktop)
- ✨ Animations CSS fluides
